# 個人翻譯網站 — 專案討論摘要

## 專案概念

青空文庫/古騰堡計畫翻譯協作站,以 GitHub 為核心基礎設施,零維運成本、盡可能開放授權,重視內容的長期保存價值。

**專案名稱**:信標文庫,網域註冊為 `beaconarchive.org`(**已定案**,2026-08-16)。全站分頁標題結尾、header 標題、footer、`/about/` 頁面已統一改用這個名稱,見 `scripts/app/layout.js` 的 `SITE_NAME` 常數。

- **核心原則**:不自建後端、不自建資料庫、全部借用外部服務的免費機制
- **協作模式**:譯者開 PR 提交,通過自動檢查即合併上線,目前規模小、無額外人工審核(細節與理由見 [翻譯者指南.md](./翻譯者指南.md#8-自動檢查)、[架構規格.md 第 6 節](./架構規格.md#6-驗證規則build-time--ci))
- **翻譯者誘因**:無金錢報酬,靠瀏覽次數/喜歡數紀錄、個人 profile 頁面

## 技術組合

| 項目 | 方案 |
|---|---|
| 內容儲存/協作 | GitHub repo(PR 提交 → 自動檢查 → 合併上線,目前無額外人工審核) |
| 版本控制 | Git history(天生留存修訂紀錄) |
| 網站託管 | Cloudflare(Workers 靜態資源部署,**已上線**,見 [架構規格.md 第 8 節](./架構規格.md#8-部署));GitHub Pages 備援**尚未設定** |
| 建置流程 | 純 Node.js build script,輸出純靜態檔案(避免用到 Cloudflare Workers/KV 或 Jekyll 專屬語法,保持可攜性)——**已實作**,見 `scripts/build.js` |
| 互動效果 | 純 JS/CSS——**尚未實作**(hover 註解、filter 搜尋等前端資源規劃放 `assets/`,還沒動工) |
| 站內搜尋/標籤過濾 | 前端 fetch `translations.json`,JS 在記憶體中 filter;量大再上 Pagefind——`translations.json` 已由 build script 產出,前端 filter UI **尚未實作** |
| EPUB 匯出 | 瀏覽器端 JSZip,純 client-side(細節未討論,**尚未實作**) |
| 授權 | 內容:CC BY-SA 4.0;程式碼:MIT——**已定案**,見 [/LICENSE](../LICENSE)、[/CONTRIBUTING.md](../CONTRIBUTING.md) |
| 使用者系統 | 借用 GitHub 帳號(僅止於譯者身分 = 資料夾名稱,登入串接、瀏覽次數/喜歡數等延伸功能尚未設計) |
| SEO | sitemap.xml + meta 標籤 + Google Search Console(細節未討論,canonical link **已實作**) |
