# 翻譯者指南

這份指南寫給想在本站發表翻譯作品的人。技術規格(檔案格式、欄位定義)見 [架構規格.md](./架構規格.md);專案整體理念見 [專案規劃.md](./專案規劃.md)。

## 這是什麼樣的協作站

- 內容全部透過 GitHub Pull Request 提交,通過自動檢查後即會合併上線,沒有帳號密碼系統,借用你的 GitHub 帳號當身分
- 沒有金錢報酬,回饋是瀏覽次數/喜歡數紀錄與你自己的個人頁面
- 翻譯來源以青空文庫、古騰堡計畫等公版/開放授權作品為主

## 開始之前

- 需要一個 GitHub 帳號
- 不需要熟悉 git——如果不會,提交步驟裡會用到 GitHub 網頁本身的功能,不用裝任何軟體
- 確認想翻的原文**確實是公版或已取得授權**可以翻譯發表(這點無法由工具自動判斷,提交時需要誠實填寫來源狀態)

## 參與流程

### 1. 打開 `/tools/new-translation/`

這是站上的一個輔助工具頁,幫你產生翻譯檔案的骨架,不用手動處理任何識別碼。

### 2. 搜尋你想翻的「作品」

- **搜尋到既有項目** → 直接選取即可
- **搜尋不到**(你是第一個翻這部作品的人)→ 切換成「新增作品」,貼上這部作品的 Wikidata 連結,或青空文庫/古騰堡的作品頁連結,工具會自動解析標題等資訊。找不到 Wikidata 條目也沒關係,手動填標題即可。

### 3. 搜尋/新增「原作者」

跟上一步同樣邏輯。搜尋不到才需要新增,能重複使用既有項目就盡量重複使用——這樣同一位作者翻過的所有作品才會彼此關聯在一起。

### 4. 選擇你翻譯依據的來源版本

同一部作品可能已經登記了不只一種來源(例如日文原文 + 英譯本)。工具會列出這部作品目前登記的「來源版本」讓你選,你選哪一個,就代表你這篇翻譯是根據哪個語言/哪個版本翻的。

- 如果你要用的版本已經登記過 → 直接選
- 如果沒有(例如你是第一個用某個英譯本轉譯的人)→ 切換「新增來源版本」,填來源連結、語言;如果那個版本本身也是別人翻譯的(如古騰堡上的英譯本),同步搜尋/新增對應的「中間譯者」項目

這些資訊(語言、出處、中間譯者)都記在「作品」底下,不是記在你自己的翻譯檔案裡——你的檔案只需要記得你選了哪個來源版本。

### 5. 產生檔案骨架

工具會用你在上一步填的中文標題自動組出檔名(標題 + 一段亂數,例如「奔跑吧梅洛斯_a1b2c3d4-....md」),frontmatter 已經幫你把 `work_id`、`edition_url` 等欄位填好。**你不需要自己想任何 ID**,也不需要碰檔名,作者、原文語言等資訊都不需要你重複填一次——網站會透過 `work_id` 自動查到。可以下載檔案,或複製內容自己貼進新檔案。

### 6. 填入譯文正文

把翻譯內容貼進檔案的正文區塊(frontmatter 以下的部分)。

### 7. 提交到你自己的目錄下

檔案要放在 `/content/translators/{你的id}/{標題}_{uuid}.md`(工具已經幫你組好完整檔名,直接用就好)。

- **第一次貢獻**:資料夾名稱建議直接用你的 GitHub 帳號,先到先得,如果跟既有資料夾重複,自動檢查或維護者會發現並請你調整
- **最簡單的提交方式**:到 repo 頁面用 GitHub 內建的「Add file」功能貼上內容,GitHub 會自動幫你開分支並建立 PR,不需要在自己電腦上裝任何工具
- 熟悉 git 的人也可以照一般流程 clone → 建分支 → commit → push → 開 PR

### 8. 自動檢查

- PR 開出後會跑自動檢查,確認 `work_id`、`edition_url` 等欄位都能對應到 repo 裡既有的資料夾/登記項目。如果檢查沒過,PR 上會直接顯示錯誤訊息,照著改一下重新 push 就好
- 通過後就會直接合併,**不會再另外等待人工審核翻譯品質或用字風格**——這是專案目前規模還小、貢獻者彼此信任度高階段的作法,不代表沒有把關,只是把關方式從「事前審查」換成「內容留在 git 歷史裡,發現問題隨時能修正或回退」。隨著參與者變多,這個作法可能會再調整,屆時會更新這份指南

### 9. 合併後自動上線

不需要自己動手部署,合併後網站會自動重新產生並上線。

## 常見問題

**想翻的作品在青空文庫/古騰堡都查不到,是我自己找到的公版書怎麼辦?**
目前只收青空文庫、古騰堡計畫這兩個來源(以及未來可能新增的其他明確來源),不接受來源不明的網址——自行認定公版狀態容易產生著作權風險,不是工具能自動判斷的事。「來源版本」的連結欄位會直接擋掉不符合這兩個來源網址格式的輸入,新增作品時務必貼青空文庫或古騰堡計畫上的實際連結。

**兩個人想翻同一部作品可以嗎?**
可以。只要都指向同一個 `work_id`,兩篇譯文會各自獨立收錄,作品頁會同時列出兩個版本,讓讀者自己選。

**我的個人 profile(`description.md`)一定要填嗎?**
不用,沒填的話譯者頁只會顯示你的資料夾名稱(帳號)跟作品列表,不影響發表。

**新增作品/作者時要自己填生平簡介嗎?**
如果有 Wikidata 連結,不用——姓名、生卒年、簡介等內容是網站在產生頁面時自動從 Wikidata 抓的,你只需要提供正確的連結。沒有 Wikidata 條目才需要手動填基本資料。

**打錯 `work_id` 或選錯來源版本會怎樣?**
PR 上的自動檢查會擋下來並告訴你哪個欄位有問題,不會等到人工審核才發現。

**授權要選哪一種?**
見 [LICENSE](../LICENSE) 與 [CONTRIBUTING.md](../CONTRIBUTING.md)。全站譯文一律採用同一種授權(CC BY-NC-ND 4.0),不需要你自己選擇,翻譯檔案裡也不用填授權欄位;原文本身的公版狀態記在該作品的來源版本資料裡(`editions[].copyright_status`),跟你這份譯文的授權是兩件事。
